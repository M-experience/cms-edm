# Modèles d'e-mails Supabase (Cms-Edm)

À coller dans Supabase : Authentication > Emails > Templates. Expéditeur : noreply@design-mutation.org (SMTP personnalisé).

- `lien-magique.html` : objet « Votre lien de connexion à Cms-Edm »
- `confirmation-inscription.html` : objet « Confirmez votre adresse pour Cms-Edm »
- `reinitialisation.html` : objet « Réinitialisation de votre mot de passe Cms-Edm »
- `changement-email.html` : objet « Confirmez votre nouvelle adresse pour Cms-Edm »
